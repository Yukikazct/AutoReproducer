# 论文标题、PDF 输入与结束判定修复（2026-10-10）

## 失败原因

保留的失败记录 `data/runtime/progress_1791629685893.jsonl` 直接输入 Neural Ordinary Differential Equations，却没有选择可运行实验。通用关键词搜索选了 `JSeam2/Neural-Ordinary-Differential-Equations`；论文方法和依赖未确认，后续执行了合成线性回归代码，最终为 `best_effort` / `inconclusive`。这既没有运行作者 Neural ODE 实验，也不能据流水线 `COMPLETED` 认定复现。

PDF 入口原来没有作者实验解析路线；解析失败或文本为空仍可能调用 LLM 并继续。现在文件验证、正文提取与首页论文身份验证在生成代码及环境交接之前执行。

## 输入契约

- 完整支持标题对应 Neural ODE、DLinear、SIREN 三个已有、固定源码版本的实验。未知标题仍使用通用路线，不宣称支持任意论文完整基准。
- PDF 匹配首页连续标题行；正文、参考文献、后续页或单独伪造元数据不能选择另一篇论文的实验。PDF SHA-256、页数及字节数写入进度与最终结果。
- 无法读取、损坏、无可读文字或无法解密的 PDF 在调用 LLM、资源搜索和训练之前拒绝。缺少解析依赖与坏 PDF 分开处理，前者可自动准备运行环境后重试。
- 标题/PDF 匹配的公开论文与作者代码分析默认开启；结果分享默认关闭，旧预设的优化和准备选项不能泄漏到输入路线。
- 作者方法实验完成仍为 `method_experiment_completed`、`is_reproduced=null`；需要论文完整基准时必须单独适配对应数据与协议。

## 结束契约

| 层级 | 结束依据 |
|---|---|
| 单步骤 | 执行者返回该步骤终态；日志中的轮数不是终态 |
| 整轮执行 | `execution_run` 终态；整轮准备、步骤和清理均返回之后才发出 |
| 阶段 | 负责人 `state` 终态，加上本阶段全部所属执行结束确认；计划中的 success 不构成证据 |
| 托管工作进程 | 父进程关闭所属作业、回收工作进程后确认 `pipeline_worker` 终态 |
| 整个任务 | `done` / `error` 加上所有开放执行和工作进程均已确认结束；提前事件挂起 |

延迟开始事件不能重开已结束的执行；失败不能被迟到的成功覆盖。工作进程消失但没有整轮终态时，父进程只有在确认所属进程清理后才记录中断，不补造成功结果。清理未确认则仍保持运行和待结束状态。
