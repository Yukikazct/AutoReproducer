供应商的单请求上下文窗口与本任务累计用量分别记录。测试已确认 12 次请求、超过 64k 的累计估算量仍可继续；缺失的实际 token 和费用保留未知。

## 关键验证边界

- 新检查证据影响下一次调查决策，独立反例可以否决补丁；原作者断言检查失败时直接否决候选。
- B 的同角色自检与 C 的独立审查使用相同工具和共享预算，切换角色或更换错误不重置预算。
- 原命令、原数据、训练与评测设置、容差保持冻结；缺少可信参考时数值等价保持未知。
- 调查工具拒绝任意排障命令、路径逃逸、私有评分文件、不可读文本及冻结哈希变化；原断言解释器限制操作、分配和递归成本。
- 原执行或探针清理未确认时保留阻断属性和回执；结果调查停止不会被吞为普通分析失败。
- 报告正文保留实验设置、结果、分析及简短调查摘要；长依据、引用和日志进入详情附件；历史重渲不启动调查。

## 正式验收缺口

`evaluation_complete=false`。目前没有登记为本轮正式 holdout 的 12 个自然新阻塞案例，也未完成 3 篇新论文的完整选定实验，因此不能声称达到净增 2 案例、接管需求降低 30% 或多智能体优于单智能体的目标。

默认可执行适配器目前覆盖 Python API 兼容恢复组件；其他三类案例仍需受信执行适配器及相应独立 Oracle。自然案例必须来自至少 6 个未用于本轮调试的仓库，先登记原始失败、完整冻结输入与正确性判据，再执行 A/B/C 各 3 次。

已保存 TabM、Graph-MLP、TabPFN 等静态筛查材料。TabM 官方数据下载尚未成功；Graph-MLP 声明 Python 3.7/PyTorch 1.7，当前受管 Python 范围不支持该解释器；TabPFN 原版没有可直接运行的完整小例脚本。补充下载了 NOTEARS、DAGMA、pygcn 的固定源码和论文：NOTEARS README 将入口明确称为 demo；pygcn 明确声明不用于复现论文报告结果；这些材料未被冒充为完整论文验收。

正式论文评测需要冻结产品并登记未使用身份，执行原配置；需要产品修改时，将该论文转为回归样本，再重新冻结并更换候选。作者执行、参考比较、独立复算和严格数值验收分别记录。
