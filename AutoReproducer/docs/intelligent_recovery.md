# 智能调查与排障

通用 PDF 复现表单提供默认关闭的“智能调查与排障”开关，沿用当前配置的模型。请求字段 `intelligent_recovery` 只接受显式布尔值，省略时为 `false`。选择其他输入方式时不会沿用上一项 PDF 任务的开关。开关经后台线程、独立工作进程和复现服务透传，不增加前置人工审核。

调查围绕实际失败展开，使用冻结源码上下文、作者运行环境元数据、明确公开的产物约定及原始作者断言等有限证据。工具拒绝路径逃逸、链接跳转、冻结哈希漂移以及未列入可读清单的数据；调查工具不执行作者训练代码。源码修改继续受原有修复权限和协议保护约束，调查开关本身不扩大可编辑范围。

`source_context` 可以按文件路径补读源码，也可以通过 `paper_pages` 选择原 PDF 页；页文本摘要须与冻结来源一致。实验理解保留方法/数据/划分/重复/单位等已知设置及缺口。局部契约首版支持同文件的纯函数和作者原有断言，用有成本上限的解释器检查；导入、模块初始化、装饰器及不支持的语法会明确拒绝。补丁审查期间，该工具可在内存中的候选函数上执行未改动的原断言，失败直接否决候选。它不会创建模型自定的 expected，也不将局部断言通过推断为完整数值等价。

默认不以固定模型请求总数或 token 总量硬切调查：`max_model_requests` 与 `max_tokens` 为 `null`。调查仍受探针、补丁和动作边界、取消与无进展停止条件约束；当前边界为 4 个探针、2 轮补丁、8 个动作，具体以本次保存的 `budget` 为准。没有供应商用量证据时记为 `unknown`，不按零用量推断。

结构化结果保存在 `data.intelligent_recovery`，包含版本、开关、运行模式、状态、冻结身份、预算、任务、用量、人工处理要求、停止原因和调查产物路径。每项任务保留触发原因、假设、探针与决策。`single` 和 `collaborative` 分别表示单角色与角色协作模式。

报告 v5 正文只展示“智能调查与处理结果”的短摘要；完整调查快照保存在同目录的 `<report>_details.md`。详情链接绑定 SHA-256，下载包会核对附件哈希。ZIP 中的 `<report>.evidence.json` 同时保留结构化调查字段，`<report>.manifest.json` 记录报告、详情及证据文件的字节数与哈希。

历史报告重渲只读取保存的结果，不调用模型、不重跑调查或实验，不改写原始结果与日志。调查完成、修复完成、作者代码运行完成、论文参考对照和独立指标核验分别表达；智能调查状态不会将未核验的论文复现结论升级为成功。

调查模型或格式错误作为辅助分析不可用保存；探针超时、取消和进程清理未确认属于运行停止条件，立即阻止后续修复。结果阶段发生这些停止条件时，保留既有作者执行与核验原始证据，报告暂不发布本次完成或论文复现成功结论。
