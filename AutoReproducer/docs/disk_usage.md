# 环境配置中的磁盘统计

环境准备阶段没有实测数据，显示“未测量”。模型返回的 `estimated_disk_gb` 和原来的固定 3 GB 不参与展示。

执行器在每个阶段结束、清理临时工作区之前记录磁盘快照，最终报告使用最终阶段的快照：

- **执行工作区文件体积**：统计代码、工作区内数据与产物，排除单独列出的依赖、安装临时文件和绘图辅助目录。
- **隔离依赖文件体积**：统计实际存在的隔离安装目录；本地持久缓存标明共享，模拟模式跳过安装时显示“未测量”。
- **Docker 镜像内容体积**：完整执行后读取本地 `docker image inspect` 的 Size 和镜像 ID；查询失败不填写默认值。

文件体积由实际文件长度读取，单位为 B/KiB/MiB/GiB；不跟随符号链接，硬链接在同一统计目录中只计一次。读取错误或超过统计预算会标明“统计不完整”。文件系统分配块数另外保留在 `allocated_bytes` 中，报告使用文件逻辑体积，不将其当作整个磁盘的物理占用。

镜像 Size 包含共享层，不代表本次任务新增占用。工作区统计可能包含已有文件，临时工作区的数值是清理前快照。本地 Python/全局包、下载缓存、工作区外数据、容器临时层和 Docker VM 实际物理空间未计入。因此各项不会合计成一个声称完整的“环境磁盘占用”。

结构化结果保存在 `execution.final.disk_usage` 和执行后的 `effective_env_config.disk_usage`。报告显示测量状态、范围、共享及清理说明；已保存的旧报告需要新建运行才会重新统计。

## 运行中的前端服务

Streamlit 的后端模块导入会被进程缓存。源码修复后若服务没有重新加载，新的任务也可能继续使用旧模块。本项目使用轮询文件监听与保存后自动重跑，避免原生文件监听漏掉变更；首次从旧配置切换时需重启对应服务。

定向重启时可通过 `AUTOREPRO_RESUME_PROGRESS` 指定已完成任务的进度文件。前端恢复其中的报告，不重启任务、不追加模型调用；未完成的任务不会被自动恢复。未指定该变量时仍打开初始页面。

绘图运行时在文字布局前为中文应用随项目提供的 Noto Sans SC 字体，覆盖生成脚本的 `rcParams`、样式重置及不支持中文的显式字体文件，保留字号。不能只在 Python 启动时设置默认字体，也不能通过隐藏缺字警告来代替修复。
