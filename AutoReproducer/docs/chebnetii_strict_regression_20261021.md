- 规划提示要求指标实现依据，以及命令行覆盖值的真实作者来源；纯空白等价引文和编译时省略的未使用依赖提案可确定性重放，原内容校验保留。

- 作者每轮打印指标按冻结顺序、各自单位和打印精度逐项核对后取均值。单个聚合输出继续支持；缺项、多项、错序和错误数值均拒绝。

## 固定实验与结果

论文：*Convolutional Neural Networks on Graphs with Chebyshev Approximation, Revisited*，PDF SHA-256 为 `c32e1ebcd886611ff66293f211e7f1b9e1ffebc6668a4b853de3bc0d2f357e37`。作者仓库为 <https://github.com/ivam-he/ChebNetII>，版本 `ded6c18cbe9673234071031767d17826ad632aca`。

真实 API 联合 PDF 与作者源码选择了仓库自带的完整八份 Cora raw 文件及原命令，在 `main/` 执行：

```text
python training.py --net ChebNetII --dataset Cora --K 10 --prop_lr 0.001 --prop_wd 0.05 --dprate 0.8 --semi_rnd True
```

保留十轮原训练、最高 1000 epoch、early stopping 200，以及最低验证损失对应模型的选择。作者循环前设置 seed=42；保留原 SEEDS 列表及执行顺序，但不把十份实际 mask 误说成分别由十个 SEEDS 独立生成。核验使用实际训练捕获的 mask，不重建随机划分。
