## 通用机制及验证边界

| 能力 | 判断依据 | 已验证的边界 |
| --- | --- | --- |
| 错误定位 | stdout/stderr、最后一次异常和 traceback | 早先已捕获的缺包错误不能触发无关安装；异常链选择最终失败 |
| 本地导入恢复 | 原始导入语句、唯一模块/包路径、固定源码哈希及依赖声明 | `lib` 模块、`src` 包、嵌套 `vendor/internal` 模块及不同脚本目录均用真实子进程验证；声明的外部包优先于同名文件，拒绝把不相关包内辅助文件提升为顶层模块 |
| 作者依赖声明 | 入口所属项目的 `pyproject.toml`、PEP 621 字段和固定源码哈希 | 模型漏填仍可读取原声明；只使用所属项目，保留条件标记，检查源码变化、格式错误和冲突；既有原生包兼容策略不变 |
| 原命令完整性 | 实际调用的静态 `argparse` 解析器和原始启动脚本 | 缺少明确必填选项时，在安装前反馈重选完整作者调用；后备补全保持入口及其他参数。动态解析器、自定义参数输入及不相关解析器不凭静态猜测阻断 |
| 有限自动修复 | 缺依赖、既有数值/路径/PyG 兼容规则及经日志验证的依赖建议 | 共享八次动作；原命令重试才决定是否解决；重复失败、取消、超时留下明确停止状态 |
| 统计解释 | 完整输出行与同一操作数的 `.mean()`/`.std()` 或 NumPy 函数调用 | 覆盖不同指标、变量名、动态前缀、函数内输出、自定义指标以及同一行相同数值的不同指标；未证明的括号不当成标准差 |
| 指标与引用 | 归一指标名、原 PDF 行列、精确证据编号及哈希 | F1 的不同平均方式保持区分；引用声明补全仍核验来源；不完整列定位只给参考差值 |
| PDF 表格恢复 | 同一份 PDF 的字符解析与页面几何解析 | 数字粘连或小数被拆开时重新解析，逐页选择更完整的结果；保留其他页的公式和原始链接上下文，不猜测或改写数字 |
| 分析上下文 | 原命令入口、原始引用、局部静态导入及冻结文件清单 | 保留全部 PDF 证据；限制仓库摘录及额外只读源码发现的体积，补读训练/评测辅助文件前核验原哈希，最终引用仍按完整分析材料核验 |
| 分析失败诊断 | 每次实际接口响应、JSON 位置及逐行来源校验 | 限次重试保留已接受行及前次失败；保存脱敏、限长响应摘录与原响应哈希，不把模型回应当成原始证据 |
| 运行中加载数据 | 原始加载器实际观测及运行后的文件核对 | 数据阶段发布明确终态；观测不完整仍保留未知状态，已观测也不升级为独立来源核验 |

自修复属于有限、可核验的恢复能力，未实现任意代码错误的自动修改。训练轮次、种子、命令、数据及已观察指标不为了通过检查而修改。
