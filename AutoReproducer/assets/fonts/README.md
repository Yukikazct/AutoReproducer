# Noto Sans SC

`NotoSansSC.ttf` is a static Regular (weight 400) instance of the official
Noto Sans SC variable font from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/notosanssc

Distributed under the SIL Open Font License in `OFL.txt`.
The instance was generated with fontTools to support Matplotlib/FreeType versions
that cannot select a weight from the variable font. No glyphs were removed.
The execution subprocess registers this font for Chinese chart labels. Docker
mounts this directory read only; font caches are stored in writable `/tmp`.
